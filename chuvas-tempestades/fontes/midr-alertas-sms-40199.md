Os alertas são importantes informações sobre a possibilidade de ocorrência de um desastre e dão à população e às autoridades os dados iniciais para que se prepararem e desenvolvam ações capazes de diminuir os danos, prejuízos e salvar vidas.

Os alertas chegam à população via SMS, TV por assinatura e pelo Google Alertas Públicos, por meio da plataforma Idap - Interface de Divulgação de Alertas Públicos <http://idap.mdr.gov.br/>, onde estados, Distrito Federal e municípios cadastram, enviam e gerenciam esses alertas.

A Sedec, responsável pela gestão do serviço nacional de difusão de alertas de desastres, busca constantemente novas alternativas tecnológicas para a emissão de alertas que possibilitem um alcance cada vez maior da população brasileira sujeita a riscos de desastres.

Desde 2017 a Secretaria Nacional de Proteção e Defesa Civil envia alertas por SMS à população que, para receber essas informações, faz um cadastro simples e rápido.

Faça como mais de 8 milhões de usuários. Cadastre-se!

### Como se cadastrar?

É muito simples e rápido! Envie um SMS com seu CEP para o número 40199. Você receberá, imediatamente, uma mensagem: Cadastro realizado com sucesso. Seu celular está apto a receber os alertas e as recomendações de defesa civil. Pronto!

### Como cancelar seu cadastro

Para cancelar, envie SAIR e o CEP para 40199. Como é permitido cadastrar mais de um CEP por celular, lembre-se de repetir este procedimento para todos os CEP cadastrados.

### Como saber se já cadastrei meu CEP?

É simples. Envie CONSULTAR para 40199.

Caso o usuário tenha CEP cadastrado, ele receberá a seguinte mensagem: “Para este número de celular existe(m) o(s) seguinte(s) CEP(s) cadastrado(s): 00000000”.

Caso o usuário não possua nenhum CEP cadastrado, ele receberá a seguinte mensagem: “Para este número de celular não existe CEP cadastrado.

### Estou tendo dificuldades com o cadastro, o cancelamento ou a consulta, como faço para pedir ajuda?

É simples. Para obter a lista de comandos, envie a palavra AJUDA para o número 40199. O sistema retornará com a seguinte mensagem: “Para cadastro envie o número do CEP para 40199. Para cancelamento envie SAIR e o CEP para 40199. Para consultar CEP cadastrado envie CONSULTAR para 40199”. Você tem todos os comandos em um só lugar para te ajudar!
