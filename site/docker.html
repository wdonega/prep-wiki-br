Passo a passo · Docker

A biblioteca em casa, em 4 passos.

O Prep Wiki BR roda num computador ou num Raspberry Pi e atende a casa toda pelo navegador: celular, tablet, outro computador. Não precisa saber programar. É instalar um programa e colar um comando.

  • PC de 64 bits
  • Raspberry Pi 4 e 5
  • outro ARM de 64 bits

Foi testado em PC com Linux, no Mac, no Raspberry Pi 5 e na Radxa Rock 5T. No Windows ainda não.

Já usa Docker? É só isto
docker run -d --name prep-wiki-br --restart unless-stopped \
  -p 8099:8080 -v ~/prep-wiki-br:/data ghcr.io/wdonega/prep-wiki-br:latest

Depois, abra http://localhost:8099. Nunca usou Docker? Siga os passos:

1Instalar o Docker 2Colar o comando 3Abrir no navegador 4Baixar os acervos

Antes de começar

O que você precisa

Um computador que fique ligado

Pode ser um PC antigo, um mini PC ou um Raspberry Pi. Enquanto ele estiver ligado, a biblioteca está no ar para a casa.

Espaço em disco

Depende do que você baixar. Os três guias do projeto somam 46 MB; um conjunto enxuto em português fica em torno de 8 GB.

Internet, só agora

Para instalar e para baixar os acervos. Depois de baixado, tudo funciona sem conexão.

1

Instale o Docker

O Docker é um programa que roda outros programas dentro de uma caixa fechada, sem espalhar arquivos pelo computador. O Prep Wiki BR vem pronto dentro de uma dessas caixas.

Baixe pelo site oficial e siga o instalador:

Linux: Docker Engine, escolhendo a sua distribuição.
Windows e Mac: Docker Desktop. Depois de instalar, abra o programa e deixe-o rodando.

Para conferir, abra o terminal (no Windows, o PowerShell) e digite:

Terminal
docker --version

Se aparecer algo como Docker version 27…, está instalado. O número pode ser outro.

2

Cole este comando

No mesmo terminal, cole o comando abaixo e aperte Enter. Na primeira vez o Docker baixa o Prep Wiki BR, o que leva alguns minutos.

docker run -d --name prep-wiki-br --restart unless-stopped \
  -p 8099:8080 -v ~/prep-wiki-br:/data ghcr.io/wdonega/prep-wiki-br:latest
docker run -d --name prep-wiki-br --restart unless-stopped -p 8099:8080 -v C:\prep-wiki-br:/data ghcr.io/wdonega/prep-wiki-br:latest

Não precisa entender o comando para usar. Mas, se quiser saber o que cada parte faz, passe o mouse ou toque numa delas:

  • -dRoda em segundo plano. Você pode fechar o terminal.
  • --name prep-wiki-brO nome da caixa, para você se referir a ela depois.
  • --restart unless-stoppedVolta sozinho quando o computador reiniciar.
  • -p 8099:8080A porta: é o 8099 do endereço que você vai abrir no navegador.
  • -v ~/prep-wiki-br:/dataA pasta do seu computador onde os acervos ficam guardados. Se não existir, é criada. Para usar outro disco, troque o caminho antes dos dois-pontos.
  • ghcr.io/wdonega/…De onde o Docker baixa o Prep Wiki BR.
3

Abra no navegador

No mesmo computador, abra este endereço:

http://localhost:8099

Na primeira vez a biblioteca está vazia, e você cai direto na tela de baixar conteúdo.

4

Escolha e baixe os acervos

Marque o que interessa e clique em Baixar. Os downloads entram numa fila, um de cada vez, e cada acervo aparece na biblioteca assim que termina. Se a internet cair no meio, ele continua de onde parou.

Para começar leve: os três guias do projeto e uma Wikipédia resumida. Dá para baixar mais depois.

Quer ver como fica antes? A demonstração é uma instalação igual a esta, com 7 acervos.

Depois de instalar

O que vale saber.

Abrir de outro aparelho

No celular ou em outro computador da mesma rede, troque localhost pelo endereço do computador onde você instalou, por exemplo http://192.168.0.20:8099. Para descobrir esse endereço no Linux:

Terminal
hostname -I

No Windows, o comando é ipconfig.

Pôr uma senha

Sem senha, qualquer pessoa na mesma rede consegue baixar e apagar acervos. Para proteger, recrie a caixa com uma senha. Os acervos baixados continuam na pasta.

Terminal
docker rm -f prep-wiki-br
docker run -d --name prep-wiki-br --restart unless-stopped \
  -p 8099:8080 -v ~/prep-wiki-br:/data \
  -e PREP_SENHA=troque-por-uma-senha-longa \
  ghcr.io/wdonega/prep-wiki-br:latest

A senha vale para a tela de baixar e apagar. Ler continua aberto para todos.

Atualizar o Prep Wiki BR

Baixe a versão nova, remova a caixa antiga e rode de novo o comando do passo 2. Os acervos não são apagados.

Terminal
docker pull ghcr.io/wdonega/prep-wiki-br:latest
docker rm -f prep-wiki-br

Os acervos têm atualização própria: quando sai uma edição nova, a tela de baixar mostra Atualizar.

Parar e ligar de novo

A biblioteca volta sozinha quando o computador reinicia. Para desligar e ligar à mão:

Terminal
docker stop prep-wiki-br
docker start prep-wiki-br

Deu errado?

Os tropeços mais comuns

Se o seu não está aqui, conte o que aconteceu no GitHub do projeto.

O Docker não está instalado, ou o terminal foi aberto antes da instalação. Feche o terminal, abra de novo e repita docker --version. No Windows e no Mac, o Docker Desktop precisa estar aberto.

O seu usuário não tem permissão para falar com o Docker. Ponha sudo na frente do comando, ou siga os passos pós-instalação do Docker para usar sem sudo.

Outro programa usa essa porta. Rode docker rm -f prep-wiki-br e repita o comando do passo 2 trocando o primeiro número, por exemplo -p 8100:8080. O endereço passa a ser http://localhost:8100.

Já existe uma caixa com esse nome, de uma tentativa anterior. Remova com docker rm -f prep-wiki-br e rode o comando de novo. Os acervos baixados continuam na pasta.

Veja se a caixa está rodando com docker ps. Se ela não aparecer na lista, docker logs prep-wiki-br mostra o que aconteceu.

Cada versão publicada traz o Prep Wiki BR em arquivo, um para PC e um para ARM. Leve o arquivo num pendrive, rode docker load -i seguido do nome do arquivo e depois o comando do passo 2. Os acervos podem ser copiados para a pasta como arquivos .zim.

Pronto. A biblioteca está acesa.
